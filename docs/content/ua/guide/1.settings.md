Відкрийте Налаштування, клацнувши іконку LangSwitcher у рядку меню → **Налаштування** (або скористайтеся комбінацією, показаною в меню).

## Вкладка «Загальні»

- **Режим розумного перетворення** — оберіть між «Жадібний рядок», «Останнє слово» або «Вимкнено». Деталі — у розділі [Розумне перетворення](/ua/getting-started/smart-conversion).
- **Запуск при вході** — автоматично стартувати LangSwitcher під час входу в систему.
- **Звук при конвертації** — короткий звуковий сигнал під час перетворення тексту.
- **Показувати сповіщення** — коротке сповіщення після кожного перетворення з тим, що було змінено.
- **Автокорекція за пробілом** — перетворювати щойно набране слово під час натискання пробіла, якщо воно схоже на слово в неправильній розкладці.
- **Відновлення тексту** — відновлює речення зі змішаними мовами та розкладками, по фрагментах. Повний гід — [Відновлення думки](/ua/guide/thought-recovery).
- **Мова** — перемикання інтерфейсу між англійською, російською, польською та українською.

## Вкладка «Гаряча клавіша»

- **Подвійний Shift** — подвійне натискання Shift за замовчуванням.
- **Подвійний Option** — подвійне швидке натискання Option натомість (комбінації Option+клавіша ніколи не перехоплюються).
- **Власна гаряча клавіша** — натисніть «Записати», щоб задати будь-яку комбінацію.

Деталі — у розділі [Налаштування гарячих клавіш](/ua/getting-started/hotkey).

## Вкладка «Розкладки»

Показує, які розкладки клавіатури визначено у вашій системі. LangSwitcher визначає розкладки автоматично — ручне налаштування не потрібне.

Повний список — у розділі [Підтримувані розкладки](/ua/getting-started/layouts).

## Вкладка «Журнал»

- **Увімкнути/вимкнути журнал** — увімкнути або вимкнути журнал перетворень.
- **Ліміт журналу** — максимальна кількість записів або «Без обмежень».
- **Перегляд журналу** — усі перетворення з вихідним текстом, результатом, вихідною/цільовою розкладкою та часом.
- **Оцінювання перетворень** — позначайте записи як правильні чи неправильні для відстеження якості.
- **Експорт JSON** — експорт усього журналу у файл JSON для аналізу чи ML-навчання.
- **Очистити журнал** — видалити всі записи.

::callout{icon="i-lucide-shield-check" color="green"}
Журнал перетворень зберігається в **локальній базі SQLite** лише на вашому Mac. Він нікуди не передається.
::
