**Коротко:** LangSwitcher не збирає, не передає та не поширює ваші дані. Уся обробка тексту відбувається виключно на вашому Mac. Жодної аналітики, телеметрії, мережевих запитів.

## 1. Збір даних

LangSwitcher **не** збирає жодних персональних даних:

- Ні текст, який ви набираєте чи перетворюєте, нікуди не надсилається
- Жодної аналітики чи телеметрії не збирається
- Жодних звітів про збої не надсилається автоматично
- Жодних куків, ідентифікаторів чи відстеження будь-якого роду
- Програма робить **нуль мережевих запитів**

## 2. Обробка тексту

Коли ви натискаєте гарячу клавішу, LangSwitcher читає виділений (або автоматично визначений) текст із поточної програми через macOS Accessibility API. Текст перетворюється між розкладками суто алгоритмічно, локальними обчисленнями. Перетворений текст вставляється назад через системний буфер обміну. Текст ніколи не залишає ваш Mac.

## 3. Журнал перетворень

Опціональний Журнал перетворень записує ваші перетворення для перегляду та оцінювання якості:

- Зберігається в **локальній базі SQLite** лише на вашому Mac
- Ніколи не передається і не синхронізується
- Повністю під вашим контролем — перегляд, експорт (JSON) чи видалення будь-коли з Налаштувань
- Журналювання можна **повністю вимкнути** в Налаштуваннях

## 4. Дозвіл Універсального доступу

LangSwitcher потребує дозвіл Універсального доступу macOS виключно для того, щоб:

- Читати виділений текст із активної програми (через `AXUIElement`)
- Емулювати події клавіатури для виділення та заміни тексту (через `CGEvent`)
- Визначати поточну розкладку клавіатури (через `TISCopyCurrentKeyboardInputSource`)

Дозвіл Універсального доступу **ніколи** не використовується для стеження за набиранням, логування клавіш чи доступу до будь-яких даних поза межами перетворення, яке ви явно запустили.

## 5. Сторонні сервіси

LangSwitcher не використовує **жодних сторонніх сервісів**, SDK, аналітичних фреймворків чи зовнішніх залежностей. Побудований повністю на системних фреймворках Apple (Swift, SwiftUI, AppKit, Carbon).

## 6. Зберігання даних

Єдині дані, які зберігає LangSwitcher:

- **Користувацькі налаштування** (гаряча клавіша, режим перетворення, мова) — у стандартних macOS `UserDefaults`
- **Журнал перетворень** (якщо ввімкнено) — у локальному файлі SQLite

Обидва повністю під вашим контролем і видаляються під час видалення програми.
