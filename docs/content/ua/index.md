#title
Виправте текст одним натисканням на macOS

#description
Набрали текст не в тій розкладці? Натисніть **Shift** двічі — і LangSwitcher миттєво його перетворить. Безкоштовна програма для macOS з відкритим кодом — виділяти текст не потрібно, розумне перетворення зробить усе саме.
